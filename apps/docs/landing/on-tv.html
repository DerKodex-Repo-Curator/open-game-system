OGS for game developers Docs

For web games built with coding agents

Your web game on a real TV. Phones are the controllers.

OGS puts your game's TV page on the living-room TV and turns every phone and iPad on the couch into a controller. Players arrive with a name and avatar. One prompt to your coding agent does the integration.

One line for your agent

Make this game OGS-compatible: follow {{SITE_URL}}/llms.txt

Paste it into Claude Code, Codex or Cursor in your game's repository. The docs tell the agent which steps your game needs, where the kits are, and which tests prove each step.

What your game gets

The TV, without a cast SDK

OGS casts once and frames your TV page. No cast button, no receiver app, no room codes on screen.

Phones as controllers

Your phone page plays in the OGS app on every phone and iPad. The whole couch follows the TV into your game.

Players with names

No sign-up or name form. A signed token gives your server each player's OGS name and avatar.

Made for agents

llms.txt, every page as Markdown, seam tests for the TV and the phone, and a starter that passes them.

How it works

  1. Start from the starter (a small game that already works with OGS) or paste the prompt into your existing game.
  2. Your agent adds the OGS pieces test-first: a TV page that goes quiet when parked, a phone page that knows who's playing, a server that checks the token.
  3. It still works in a plain browser. Ship it anywhere you like; inside OGS it gets the TV and the couch.

Where OGS is today

OGS is in a private beta: the iPhone and iPad app is on TestFlight, and it casts to Chromecast or any TV browser. Games join the catalogue by pull request. The waitlist is how we pick the next games and the developers who get the app first.
